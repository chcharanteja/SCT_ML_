# Customer Segmentation using K-Means Clustering

## Overview
This project applies the K-Means Clustering algorithm to segment customers based on their annual income and spending score.

## Objectives
- Load customer dataset
- Apply the Elbow Method
- Train the K-Means model
- Visualize customer segments

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm
- K-Means Clustering

## Outcome
Successfully grouped customers into different clusters and visualized customer behavior using unsupervised learning techniques.
